# Target Journey Radar

Сделай дизайн публичной страницы «Монитор полётов» — визуальный обзор инвестиционных идей на пути к цели. Это аналог сервиса Flightradar или https://planefinder.net/ для финансовой аналитики. Каждый самолет - это инвестиционная рекомендация (инвестидея)

Это не дашборд с кучей виджетов. Одна главная сцена: идеи как точки на маршруте. Остальное — фильтры, краткая сводка и деталь по клику. Дизайн сделай своим: композиция, типографика, цвет, плотность. Подписи зон и набор показателей можно переосмыслить, если смысл останется ясным. Ниже — что уже работает в прототипе и что должно читаться с первого взгляда.

## Метафора
Каждая идея — точка на «полёте» к целевой цене.
- По вертикали — фактическая доходность в процентах. Шкала линейная: +20% визуально вдвое выше +10%. Ноль выделен.
- По горизонтали — какая доля пути до цели уже пройдена: 0 → 0,2x → 0,5x → 0,8x → 1X Цель.
- Слева отдельная зона для идей с доходностью ниже нуля (ещё не «завелись»).
- Справа отдельная зона-склад для идей, которые уже закрылись по цели (1x).
- Между ними три участка пути к цели.

## Пять зон (смысл сейчас)
1. Не завелись — доходность ниже нуля.
2. Взлетает — пройдено до 20% пути к цели (до 0,2x).
3. В полёте — от 20% до 80% (0,2x–0,8x). Сюда же часто кладут идеи без целевой цены с плюсом или нулём — они стоят на отметке 0,5x.
4. Финишная прямая — больше 80% пути, цель ещё не взята.
5. Достигли цели — только закрытые идеи, которые дошли до целевой цены. Активная идея в эту правую зону не попадает, даже если цена уже у цели.

## Что за точка
- Все точки-"самолеты" одного размера. Если идея на лонг - зеленые, на шорт - красные. Без подписей тикеров на самом графике (шум).
- Цвет точки = зона.
- При наведении подробная информация : тикер , аналитик, текущая доходность, апсайд, аналитик; если идея закрыта — «закрыта»; если без цели — «идея без целевой цены».
- Клик открывает карточку: название, тикер, аналитик, статус (Активна / Закрыта), цена и дата открытия, текущая цена и доходность, целевая цена и апсайд, . Строку «до цели / апсайд» показывай только у активных. У закрытых её нет. У идей без цели — «цели нет».

## Идеи без целевой цены
Они тоже на графике. Плюс и ноль — в середине на 0,5x. Минус — в левой красной зоне пропорционально доходности. Визуально точка обычная; отличие только в подсказке и в карточке.

## Фильтры (все влияют на график, сводку и список)
1. Период по дате открытия идеи:
   - За всё время (в прототипе — с 1 июня 2026)
   - За месяц (последние 30 дней)
   - За неделю (последние 7 дней)
   Рядом с каждой опцией — число идей.
2. Книга: Активные / Закрытые / Все идеи  — тоже с числами.
3. Аналитик: поле поиска. По мере ввода — подсказки авторов, у кого есть идеи в выбранном периоде, с числом идей. Выбор одного автора оставляет на экране только его идеи. Сброс — «Все аналитики».
4. Дополнительно можно фильтровать по зоне или «Без цели» (в прототипе — пилюли над таблицей).

При смене фильтра шкала доходности перестраивается по идеям, которые сейчас на экране.

## Сводка сверху
Пять крупных показателей по зонам текущего набора (не «всего мира»):
- Не завелись
- Взлетает
- В полёте
- Финишная прямая
- Достигли цели

## Таблица / список
Под графиком — список тех же идей: стадия, тикер (и пометка шорт, если шорт), название + дата открытия, аналитик, цена старта, текущая/закрытия, цель, доходность, апсайд, пройдено. У закрытой идеи в колонке цены — цена закрытия, в доходности — результат на момент закрытия. У идей без цели цель и апсайд — прочерк.

## Важные смысловые правила (не ломай в дизайне)
- Выборка всегда по дате открытия идеи, не по дате закрытия.
- Активные и закрытые живут на одном графике; закрытые могут быть в любой из пяти зон; активные — только в первых четырёх.
- Источник данных — база Invest-Idei; подпись среза и периода где-то на экране уместна.
- Это монитор идей аналитиков, не торговый терминал и не портфель пользователя. - сделать возможность увеличения области на графике, если самолетов много и они накладываются друг на друга

## Чего не делать в первой версии дизайна
- Не подключай реальные API и ключи.
- Не считай доходность «от себя» — пока хватит правдоподобных демо-данных, чтобы показать композицию.
- Не превращай первый экран в панель из десятков карточек, KPI-полосок и мелких бейджей поверх графика.
- Не рисуй названия идей прямо на точках.

## Что я хочу от дизайна
Сильная визуальная сцена «маршрут до цели», понятные зоны, спокойные фильтры, удобная карточка по клику, нормальный мобильный вид. Можно предложить другие названия зон, другой акцент (например сильнее выделить финиш или закрытые), другую раскладку фильтров и таблицы — если метафора полёта и сравнение идей по доходности / пути к цели останутся читаемыми. В качестве референса вида, шрифтов , логики https://planefinder.net/
